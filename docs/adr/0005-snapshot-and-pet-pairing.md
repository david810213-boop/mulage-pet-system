# 0005 項目名稱存快照；以（會員, 寵物名）識別同一隻寵物

## 背景
服務項目會改名、改價；歷史訂單應顯示當時的名稱與金額。預約與現場單建立時，寵物檔案可能還沒建立或之後改過，訂單沒有寵物外鍵。

## 決策
- `AppointmentItem`／`WalkInOrderItem` 的品項名稱、價格、積分是**快照**，不是即時關聯；服務項目改名不影響歷史紀錄。
- 判斷「同一隻寵物」（首次體驗、回洗資格、消費紀錄）以（會員 id, 寵物名稱）文字配對；沒有綁定會員的現場單無法識別歷史，一律不適用相關優惠。

## 後果
- 寵物改名會讓舊紀錄對不上，這是已知限制。
- 新功能需要「這隻寵物的歷史」時，沿用同一套配對（見 `PetConsumptionHistoryService`）。
