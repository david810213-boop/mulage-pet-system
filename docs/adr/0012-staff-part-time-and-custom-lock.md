# 0012 代班員工、員工停用與狗狗固定組合（客製化鎖定）

## 背景
- 店家有不少 part-time 代班美容師，流動率高。代班只幫忙美容、不用系統，但積分要記在本人名下，月底照積分算薪。原本員工一定要有帳號密碼，離職也沒辦法停用，會一直留在經手人選單裡。
- 狗狗原本只能鎖定一項套餐。改成「精緻洗＋依體型加購」（0011）之後，店家想幫個別狗狗固定一整組項目（例如精緻洗＋HC＋局部修剪＋刷牙），而且價格固定在鎖定當時。

## 決策
### 代班與停用
- 代班仍是 STAFF 角色的 `users` 資料列（積分紀錄 `staff_id` 必填，要有對應的人），以 `is_part_time` 標記；帳號密碼是系統產生的佔位值，登入時一律拒絕。
- 代班姓名直接存成「王小美（代班）」：所有報表、匯出、選單都讀 `name`，不用逐頁改顯示邏輯。轉正職時補設帳號密碼並拿掉這個標記，積分紀錄不變。
- 停用沿用既有的 `is_active`：停用後不能登入、不出現在經手人選單與切換身分清單、不收 LINE 通知；資料不刪除，歷史積分與報表照常顯示。只有店長（管理員）能新增、停用、轉正職。
- 已登入的裝置在登入有效期限（1 天）到期前仍可使用；為了不讓每個請求多查一次資料庫，不在攔截器即時檢查停用狀態。

### 固定組合
- 新表 `pet_locked_items`（寵物、服務項目、固定價）存組合；`Pet.lockedGroomingItemId` 仍指向組合裡的精緻洗，菜單篩選沿用原本的鎖定邏輯（其他體型套餐隱藏、加購照常顯示）。組合一定要有、而且只能有一項精緻洗。
- 價格固定（店家決定）：預約、到店開單、現場開單、核對加項目時，組合裡的項目一律用固定價；固定價跟目前價格不同時品項名稱加註「（固定組合價）」方便對帳。
- 組合一律帶入：顧客線上預約時整組列在上方、不能移除，可以另外加購；店員開單時後端補上漏選的組合項目，核對時店員仍可移除。
- 鎖定方式：結帳頁按「鎖定本次服務項目為固定組合」，把這張單的服務項目照這張單的價格存成組合（同一項目的 $0 副組成列取最高價那列）。原本的單項鎖定 API 保留，轉成只有一項的組合。
- 組合裡的精緻洗下架時整組不算數，回到依體重篩選；其他項目下架只略過那一項。
- 既有的單項鎖定由 V21 轉成「只有一項的組合」，價格固定為遷移當時的價格。

## 後果
- 預約還沒到店開單前的金額（`selectedItems` 是即時關聯，不是快照）每次計算都會查一次這隻寵物的固定價，多一到兩條查詢。
- 組合內容要修改時，目前是「解鎖 → 下次結帳重新鎖定」，沒有單獨的組合編輯畫面。
